# Little Letter Tracer

A simple offline children's alphabet learning website.

## Features

- All 26 English letters
- Uppercase and lowercase tracing
- Spoken letter names
- Spoken phonics sounds
- Example words and emojis
- Mouse, stylus, and touchscreen tracing
- Progress stars
- No database or server required

## Run it

Open `index.html` in a modern browser such as Chrome, Edge, Safari, or Firefox.

For the clearest speech output, allow the browser to use the device's built-in English voice.

## Note

The phonics audio uses the browser's built-in speech synthesis. Pronunciation can differ slightly between devices and browsers.
